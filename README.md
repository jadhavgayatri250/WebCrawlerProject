# WebCrawlerProject

WebCrawlerProject is a Java-based Web Crawler application developed using Java, JSoup and SQLite.

## Features

- User Registration and Login
- Secure Login Authentication
- Crawl Web Pages
- Extract Website Information
- Store Crawled URLs
- Search Crawled Data
- View Crawled URLs
- Concurrent Web Crawling
- Crawling Statistics
- User Dashboard
- Logout

## Technologies Used

- Java
- Java Swing
- JSoup
- SQLite
- JDBC
- Multithreading
- HTML

## Project Description

WebCrawlerProject helps users crawl web pages and extract useful website information. It allows users to register, log in securely, crawl websites, store extracted URLs in a SQLite database, search crawled data, and view crawling statistics through a user-friendly interface.

## How to Run

### Step 1: Clone the Repository
bash
git clone <repository-url>
### Step 2: Open the Project Folder
bash
cd WebCrawlerProject
### Step 3: Open the Project

Open the project in IntelliJ IDEA or Eclipse.

### Step 4: Add Required Libraries

Make sure the following libraries are available:

- JSoup
- SQLite JDBC Driver

### Step 5: Run the Application

Run the following file:
bash
Main.java
